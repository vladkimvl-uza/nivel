# Конвейер первого экрана: рабочие скрипты 06.10.2026

Справочная копия скриптов, которыми из роликов владельца собраны ролики прототипа (`../index.html`). Сами ролики в git не входят (`.gitignore`, папка `../media/`).

- `prep/` — подготовка исходников: поиск углов экранов и трекинг (`detect.py`, `track.py`, `track_seq.py`, `quadlib.py`, `robfit.py`, `smooth.py`), замена содержимого экранов и отражения в стекле корпуса (`render14*.py`, `refl*.py`, `comp.py`), размытие постеров и логотипов (`posters_chk.py`, `logochk.py`), цвет «оригинал» и «фирменный» (`grade.py`), манифест (`manifest.py`).
- `montage/` — монтаж v2: сегменты (`seg_cpu.py`, `seg_case.py`, `casefx.py`), сборка по шагам (`assemble.py`, `timeline-*.json`), кодирование для прокрутки (`encode.sh`: H.264 без B-кадров, ключевой кадр каждые 6 кадров, faststart), снимки собственных экранов (`screens.html`, `scr.cjs` — Playwright headless).
- `manifest.json` — что вошло в монтаж: файлы, длительности, вес, источники, что заменено и что размыто.

Пути в скриптах — абсолютные пути рабочей папки сессии. Для своей съёмки владельца скрипты переносятся и запускаются заново; Python с OpenCV 4.13, ffmpeg. Лицензии и риски — `../LICENSES.md`, источники — `../SOURCES.md`.
- `bg/` — фон ниже первого экрана (раунд 9, 06–07.10.2026: 3D-сцена «стол мастера» заменена реальными роликами).
  - `clips.py [x][y][t][i]` — ролики этапов из исходников 1080p: перевод дневных стоков в ночь (`hv/work/nightmatch.py`), «фирменный» цвет (`prep/grade.py`) и `finish()` — всё, кроме янтаря 16–44°, обесцвечено до графита; размытие логотипов и надписей по трекингу (LK + RANSAC, гомография от опорного кадра); свои кадрирования для компьютера (1280×720) и телефона (360×640). Пишет `int/<k>-{d,m}.mp4` (CRF 8) и лист кадров `int/<k>-chk.jpg` для просмотра.
  - `encode-clips.sh [out]` — для сайта: x, y, i — H.264 без B-кадров, ключ каждые 6 кадров, `+faststart` (перемотка, как у первого экрана); t — петля с обычной структурой GOP; без звука; компьютер 960×540 CRF 28, телефон 360×640 CRF 29.
  - `stills.py [out]` — `k` (свет лампы в расфокусе, «Как работаем» и конфигуратор), `c` (тёмный фон с пятном лампы — цены, акт, гарантия, финал) и постеры этапов `x/y/t/i` для reduced motion и режима без видео.
  - `render-logo.cjs`, `encode-logo.py` — финал «Посадка по допуску» (без изменений с раунда 8). `media/bg/grain.webp` — плитка зерна раунда 8 (её скрипт `post-scene.py` вместе с 3D-сценой убран; копия — в рабочей папке `r9/bak/pipeline-bg/`).
  - Python 3 с OpenCV и NumPy, ffmpeg. Скрипт страницы: `../bg.js` → `../bg.min.js` (esbuild `--minify`).
