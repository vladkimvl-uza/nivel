## 5. Как страница использует видео

- Постер шага 01 грузится сразу (LCP). Ролик качается не на `load`, а по первой прокрутке или касанию либо когда браузер свободен (`requestIdleCallback`, не позже 2,5 с). Ролик целиком загружается в память (blob), прокрутка ставит `currentTime`.
- Перемотка: догон к цели, при рывке больше 0,6 с ролика — сразу к цели, без промежуточных кадров. После остановки прокрутки внутри растворения показывается ближайший чистый кадр («магнит»).
- Постеры вместо видео: `prefers-reduced-motion`, «Без анимации», экономия трафика, сеть 2g/3g (и downlink < 2 Мбит/с, если тип сети не 4g), память < 2 ГБ. Сеть проверяется дважды: при загрузке и в момент старта ролика.
- Язык по умолчанию — узбекский (переключатель: UZ, затем RU).
- Для проверки: `?hero=posters|video`, `?motion=off`, `?color=brand|orig`, `?lang=ru`.

## 6. Что ещё снять

Стоковые ролики — временный слой. Своя ночная съёмка первой сборки при одной тёплой лампе (стол, экран со сметой, корпус под нагрузкой, монтаж на месте) заменит все четыре отрезка, и тогда подпись «не работа студии» уйдёт. Заложить её в план первого заказа.

### 7.2 Как играет

- Прокрутка = время заказа: в полосах «Закупка», «Сборка» ролик перематывается по доле закрепления, в «Идеях» — по доле раздела; в полосе «Тест» петля, часы идут по прокрутке (8 ч за полосу) и сами (1 ч за 4 с).
- Остановились — через 0,45 с ролик доигрывает сам (родное воспроизведение); в «Сборке» — только до конца главы текущего пункта списка, дальше ждёт, пока список (одна деталь за 2,2 с) перейдёт к следующему; в «Закупке» — только до доли n/9 по числу пришедших чеков (процессор поворачивается к лампе вместе с чеками).
- Стоп: скрытая вкладка, «Без анимации», prefers-reduced-motion. Reduced motion и режим без видео (экономия трафика, 2g/3g, память < 2 ГБ; на телефоне < 4 ГБ; `?bg=frames`) — постеры конечного состояния этапа, **ни одного видео фона** (проверено 07.10: 0 запросов mp4; единственный `<video>` на странице — пустой элемент первого экрана без src). При Fast 3G ворота видео переводят страницу в режим постеров — это ожидаемо: видео под Fast 3G не грузится.
- Лениво: ролик этапа создаётся, когда открыт предыдущий раздел; на телефоне дальние ролики освобождаются. `k` и `c` (2–5 КБ) берутся заранее, при первом появлении фона, — без мигания при быстрой прокрутке.
