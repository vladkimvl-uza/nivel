Дата: 05.10.2026. Автор: главный архитектор (Claude Code). Основа — [ARCHITECTURE.md](ARCHITECTURE.md); номера разделов в скобках ссылаются на неё.

- Разработку ведут агенты Claude Code; владелец проверяет, наполняет каталог и цены, ведёт заказы.

- Код и имена — по-английски; тексты интерфейса — uz и ru; документ — деловой русский.

## 1. Как работаем

### 1.1. Роли

| Роль | Кто | Что делает |
| --- | --- | --- |
| Интегратор | один агент на весь проект | WP-00; сливает ветки по одной; единственный правит корневой `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, миграции и `packages/db/src/schema/index.ts`; ведёт `OWNERSHIP.md` и ADR |
| Агент пакета | по агенту на WP | работает в своём worktree и ветке, только в своих путях; заявки на зависимость, колонку или изменение контракта — в описании ветки |
| Архитектор | этот документ и ADR | изменение замороженных контрактов (`packages/domain/src/**/types.ts`) — только через ADR |
| Владелец | человек | решения, приёмка по чек-листу раз в неделю, контент, внешние действия |

### 1.2. Правила веток и слияния

- Worktree: `git worktree add C:\Users\v.kim\setup-studio-wt\wp-NN -b wp/NN-<имя>`; файл `.env.local` worktree задаёт `NIVEL_SLOT=<1–9>` (порты `3100 + 100 × slot`, префикс тестовых баз `nivel_s<slot>_`).
- Перед запросом слияния: `pnpm ci:local` зелёный, `check-ownership` без нарушений, описание ветки — что сделано, контракты, заявки интегратору.
- Интегратор: rebase на `main` → `pnpm install` → `pnpm db:generate` (если менялась схема) → полный `pnpm ci:local` → слияние → сообщение остальным о перебазировании.
- Одновременно — не больше 5–6 агентов: память Docker Desktop (7,6 ГиБ на всю машину, рядом чужие контейнеры) и время владельца на приёмку.
- Чужие контейнеры (gas-platform, ai-fin-consultant, ept, esg-tariffs) и порты 8081, 8010, 8091, 8092, 8095, 8443, 8480, 5433 не трогать; Docker — только с `-p nivel-*`.

### 1.3. Готовность пакета (Definition of Done)

- Критерии приёмки пакета выполнены, тесты из его карточки написаны и проходят.
- `pnpm ci:local` зелёный; покрытие `domain` ≥ 90 % (деньги ≥ 95 %).
- Новые тексты — ключи в своём пространстве имён на uz и ru; узбекский черновик агента помечен в `meta` как `status: "draft"` и уходит переводчику (`i18n:export`); выпуск R0 требует `reviewed` для своих пространств.
- Демо-данные — только с `is_demo`; юридические тексты — только `stub` с плашкой.
- Секретов в коде нет (`gitleaks`); новые переменные — в `.env.example` и zod-схеме `packages/config`.
- Изменения контракта — ADR и метка `contract`; изменения схемы — заявка интегратору.
