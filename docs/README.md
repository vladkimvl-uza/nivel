# Документы проекта

Проект setup-studio (рабочее название папки). Бренд — Nivel («Нивел»), логотип nivel-1 «Отметка уровня»: SVG — `brand/logos-v2/nivel-1*.svg`, лист — [brand/logo-concepts-v2.html](brand/logo-concepts-v2.html); решения владельца от 05.10.2026. Дата: 05.10.2026. Оглавление всех документов в `docs/` и порядок чтения для владельца.

## Коротко

1. Начинать с [DECISIONS.md](DECISIONS.md): там 27 решений с вариантами, ценой и рекомендацией; первые срочные — Р-5 (основная работа и регистрация ЯТТ) и Р-14 (режим занятости), ответ нужен до 12.10.2026.
2. [CONCEPT.md](CONCEPT.md) объясняет модель целиком: схема денег, плата, гарантия, продукт, финансы, дорожная карта; раздел 12 — какие значения выбраны, где блоки расходились.
3. [RISKS.md](RISKS.md) — реестр из 139 рисков с мерами и сроками; [MARKETING.md](MARKETING.md) — план продвижения на 90 дней.
4. Блоки `research/` — исследование с источниками. Где блок расходится со сводными документами, вверху блока стоит пометка «Актуализация 05.10.2026» с действующими значениями.
5. Решения владельца от 05.10.2026, принятые после выхода сводных документов, главнее рекомендаций DECISIONS по Р-13, Р-15–Р-18, Р-22:
   - название Nivel; опрос 07–13.10 отменён; до вывески и платной рекламы — заключение патентного поверенного и своя заявка на знак в классах 35, 37, 42; запасные — Setmont, Bevelset, Kantel;
   - логотип nivel-1; цвета: асфальт #1D1D1B, сигнальный оранжевый #D9501A (на тёмном #F06A30), бумага #F1EFEA; слово — Manrope Bold в контурах; для текстов сайта нужен шрифт с U+02BB (в Manrope его нет); знак в аватаре мелковат — доработать;
   - адреса: nivel.uz (основной), niveluz.com (запасной), канал @nivel (запасной @niveluz), бот @niveluzbot; регистрирует владелец сам или по его согласию;
   - живые макеты трёх направлений в палитре nivel-1: Б «Паспорт сборки» (основа), А «Мастерская», В «Ночная съёмка»; «Ташкентский модернизм» исключён; выбор по макетам;
   - разработку сайта, бота, админки и ИИ-консультанта ведёт Claude Code; оценки 300–460 и 525–830 ч срок больше не ограничивают; узкие места — каталог и цены, узбекская оферта, контент, время владельца на проверку, ИП и работодатель.
6. Первый локальный коммит — 05.10.2026 (861c486); правило — коммит после каждого этапа; приватный GitHub — после согласия владельца. До коммита параллельная работа перезаписала лист логотипов и блок 14b; лист Setmont восстановлен из рабочей копии.
