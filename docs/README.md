# Документы проекта

Проект setup-studio (рабочее название; рекомендуемое название бренда — Setmont). Дата: 05.10.2026. Оглавление всех документов в `docs/` и порядок чтения для владельца.

## Коротко

1. Начинать с [DECISIONS.md](DECISIONS.md): там 27 решений с вариантами, ценой и рекомендацией; первые срочные — Р-5 (основная работа и регистрация ЯТТ) и Р-14 (режим занятости), ответ нужен до 12.10.2026.
2. [CONCEPT.md](CONCEPT.md) объясняет модель целиком: схема денег, плата, гарантия, продукт, финансы, дорожная карта; раздел 12 — какие значения выбраны, где блоки расходились.
3. [RISKS.md](RISKS.md) — реестр из 138 рисков с мерами и сроками; [MARKETING.md](MARKETING.md) — план продвижения на 90 дней.
4. Блоки `research/` — исследование с источниками. Где блок расходится со сводными документами, вверху блока стоит пометка «Актуализация 05.10.2026» с действующими значениями.
5. Второй раунд названий выполнен двумя параллельными проверками; обе сведены в DECISIONS, Р-16 и Р-17.
6. Файлы не под версионным контролем: в репозитории нет ни одного коммита. 05.10.2026 параллельная работа перезаписала лист логотипов и блок 14b; лист Setmont восстановлен из рабочей копии.
