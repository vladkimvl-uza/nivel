# ADR-006. Тема сайта

- Дата: 06.10.2026, пересмотрено 06.10.2026 после решения владельца «без дневной версии». Статус: принято; спайк шрифтов — запасной вариант. Основа: ARCHITECTURE 5.7, 5.8; DECISIONS Р-18; BUILD_PLAN 3, 4.2.

## Контекст

- Сначала было три направления из макетов (Б «Паспорт», А «Мастерская», В «Ночь») с выбором в админке. Затем владелец выбрал «В + А: ночь и день»: две темы, режим по местному времени.
- 06.10.2026 владелец решил: **только ночной режим «Ночная съёмка»**. Первый экран — его видео на прокрутке. Документальные блоки (смета со штампами, паспорт сборки) взяты из Б.
- Компоненты не должны знать о теме.

## Решение

- Тема одна: `night`. Layout ставит `<html data-theme="night">`. Переключателя, выбора по времени и настройки `ops.settings.site.theme` нет.
- Атрибут `data-theme` остаётся. Так вторую тему можно вернуть без правки компонентов.
- Слой 1 — примитивы палитры nivel-1 и токены в `packages/ui/src/themes/tokens.ts`; из них генерируется `themes.css` (только переменные).
- Слой 2 — семантические токены `--nv-*`. Tailwind 4 ссылается только на семантику.
- Документальные примитивы (смета, паспорт, штамп, бирка) лежат на «бумаге» `.nv-paper` внутри ночной страницы и в PDF.
- Админка (WP-10) использует те же токены: своих тем у неё нет.
- Сырые HEX и `rgb()` вне файлов тем запрещены (`check-antilist`).

## Переход

- WP-09 слит 06.10.2026 с двумя темами «день» и «ночь» и выбором по времени; e2e ждёт `data-theme="day"`.
- Пакет «WP-09 ночь» снимает дневную тему, выбор по времени и переключатель, `defaultTheme` становится `night`. При его слиянии e2e переходит на `night`.

## Спайк «Шрифты» (BUILD_PLAN 4.2)

- План: `next/font/local` с `preload: false` у всех начертаний и ручной `<link rel="preload">` только для основного текстового шрифта.
- Факт: `next/font/local` не отдаёт URL файла (имя с хэшем назначает сборка). Поэтому ручной `<link rel="preload">` без второй копии файла невозможен.
- Применён запасной вариант из таблицы спайков: шрифты через `next/font/local`, предзагрузка у одного начертания (Fira Sans 400, `preload: true`), у остальных `preload: false`, `display: "swap"`.
- С одной темой вопрос предзагрузки шрифта другой темы снят.

## Последствия

- WP-09 владеет набором шрифтов (woff2 OFL, latin, latin-ext, cyrillic; глифы U+02BB/U+02BC) и токенами.
- Бюджет: ≤ 3 начертания на страницу, предзагрузка одного (ARCHITECTURE 5.8).
