# ADR-006. Тема сайта во время работы

- Дата: 06.10.2026. Статус: принято; спайк шрифтов — запасной вариант. Основа: ARCHITECTURE 5.7, 5.8; DECISIONS Р-18; BUILD_PLAN 3, 4.2.

## Контекст

- Три направления дизайна (Б «Паспорт», А «Мастерская», В «Ночь»); выбор владельца — к 26.10.2026. До выбора сайт работает в теме Б.
- Смена темы не должна требовать выпуска кода; компоненты не должны знать о теме.

## Решение

- `<html data-theme="b|a|v">` из `ops.settings.site.theme` (по умолчанию `b`); владелец переключает в админке, сайт перевыпускает тег `settings`.
- Слой 1 — примитивы палитры nivel-1 и файлы тем `themes/{b-pasport,a-masterskaya,v-noch}.css` (только переменные); слой 2 — семантические токены `--nv-*`; Tailwind 4 ссылается только на семантику.
- Сырые HEX и `rgb()` вне файлов тем запрещены (`check-antilist`).
- Компоненты направления — `packages/ui/src/direction/<b|a|v>/` (WP-20), строятся только для выбранного.

## Проверено в WP-00

- `packages/ui` экспортирует `themes` и `defaultTheme = "b"`; layout сайта ставит `data-theme`. Токены и файлы тем — WP-09.

## Спайк «Шрифты» (BUILD_PLAN 4.2)

- План: `next/font/local` с `preload: false` у всех начертаний и ручной `<link rel="preload">` только для основного текстового шрифта выбранной темы.
- Факт: `next/font/local` не отдаёт URL файла (имя с хэшем назначает сборка), поэтому ручной `<link rel="preload">` без второй копии файла невозможен.
- Применён запасной вариант из таблицы спайков: шрифты темы Б через `next/font/local`, предзагрузка — у одного (Fira Sans 400, `preload: true`), остальные — `preload: false`, `display: "swap"`.
- Следствие для тем А и В: при смене темы основной текстовый шрифт новой темы не предзагружается до перевыпуска, где WP-09 переключит `preload` на шрифт выбранной темы. На LCP влияет только `display: swap` (текст виден сразу системным шрифтом).

## Последствия

- WP-09 владеет набором шрифтов (woff2 OFL, latin, latin-ext, cyrillic; глифы U+02BB/U+02BC) и переключением предзагрузки по теме.
- Бюджет: ≤ 3 начертания на страницу, предзагрузка одного (ARCHITECTURE 5.8).
