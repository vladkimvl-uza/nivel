# @nivel/ui — дизайн-система «Ночная съёмка»

Источник значений: `docs/design/day-night/DESIGN_SYSTEM.md` (колонка ночи) и прототип `index.html` рядом с ним. Решение владельца от 06.10.2026 (Р-18, ADR-006): тема одна — ночь. Дневной версии нет; выбора по времени, переключателя и запоминания выбора тоже нет.

## Три входа: какой для какой среды

- Ядро: `src/index.ts` (имя пакета `@nivel/ui`). Только `.ts`, без react и JSX: токены ночи (`themeTokens`), `brand`, `defaultTheme` (`"night"`), `sceneLight`, шрифты (`fontFaces`, `fontFile`), `formatAmount`/`formatBp`. Грузится в чистом Node (`node src/main.ts` у worker и bot, рендер PDF в `@nivel/pdf`) и в браузере. Тест `entries.test.ts` запускает его в отдельном процессе Node и следит, чтобы в графе ядра не появились `.tsx` и react.
- React: `src/react.ts` (путь `@nivel/ui/react`). Примитивы: `Button`, `TextField`, `Select`, `Paper`, `EstimateTable`, `SumsTable`, `Stamp`, `RoundStamp`, `Tag`, `Badge`, `Money`. Только для кода, который собирает сборщик (Next.js с `transpilePackages`) или vitest; из worker, bot и pdf его не импортировать. Логотип: `LogoMark`, `LogoLockup`, `LogoLoader`, `LogoIntro`.
- Ядро заставки: `src/logo-motion/index.ts` (путь `@nivel/ui/logo-motion`, см. «Логотип и движение»). Чистый TS без react, но с `three`; его не импортирует статически ни один другой вход. `LogoIntro` подгружает его через `import()`.

## Подключение (apps/web)

- Стили: один раз в CSS приложения `@import "@nivel/ui/styles.css"` (или относительным путём к `src/styles/index.css`). Это темы, `@font-face`, база, примитивы. Компоненты пишут `var(--ink)`, `var(--bg)`, а не цвета.
- Корень страницы: `<html lang={…} data-theme={defaultTheme}>`. Сервер рисует `"night"`, скрипта и `suppressHydrationWarning` не нужно: атрибут не меняется. Страница без атрибута тоже ночная (`:root` и `[data-theme="night"]` — одно правило).
- Атрибут `data-theme` оставлен намеренно: вторую тему можно вернуть, не трогая компоненты (член в `themes`, набор в `themeTokens`; правило в `themes.css` генератор допишет сам после `build-css.mjs`).
- `<meta name="theme-color">` — значение `themeTokens.night.themeColor`.
- Слой документов: `Paper`, `EstimateTable`/`EstimateRow`, `SumsTable`, `Stamp`/`RoundStamp` (один раз на странице `StampInkDefs`), `Tag`, `Badge` (`demo`, `draft`, `visualization`, `sample`). Документы лежат на «бумаге» `.nv-paper` внутри ночной страницы. Штампы `rect` и `RoundStamp` рассчитаны только на бумагу; малый штамп (`variant="small"`) вне бумаги берёт `--accent-ink`, на бумаге `--stamp`.
- Вспомогательные классы: `.nv-lamp` (тёплое пятно лампы за блоком, всегда включено), `.nv-stamp--press` (оттиск штампа за 450 мс, при «уменьшить движение» отключён), `.nv-sr` (текст только для чтения с экрана).
- Тексты (uz/ru) приходят из вызывающего кода: пакет переводов не содержит, обязательные подписи нельзя оставить пустыми.
- Свет 3D-сцены для WP-21: `sceneLight` (ядро), только ночной набор. Первый экран сайта теперь видео владельца; экспорт оставлен на будущее.
- Шрифты для PDF: `fontFile(face, "ttf")` отдаёт имя файла в `fonts/`; путь к каталогу — `import.meta.resolve("@nivel/ui/fonts/…")`.

## Что и где

- `src/themes/tokens.ts` — все цвета ночи и бумаги (сырые цвета разрешены только в `themes/`); `themes.css` генерируется из него; `src/themes/ids.ts` — `themes`, `defaultTheme`.
- `src/fonts/catalog.ts` — девять начертаний; файлы woff2 (сайт) и TTF (PDF) в `fonts/`, лицензии OFL в `fonts/licenses/`.
- После правки токенов или шрифтов: `pnpm exec node packages/ui/scripts/build-css.mjs` (тест падает, если CSS устарел).
- Снимки Playwright: каталог `e2e/` и `playwright.config.ts` принадлежат интегратору; страницы-витрины примитивов пока нет, снимки не сняты.
- Проверки: `pnpm test` (контраст пар токенов ночи и бумаги ≥ 4,5:1; глифы U+02BB и U+02BC в каждом файле шрифта; все классы компонентов есть в CSS; в стилях нет `[data-theme="day"]`; `defaultTheme === "night"`), `pnpm check:antilist`.

## Логотип и движение (Р-17, «Посадка по допуску»)

Концепт и решения: `docs/design/logo-motion/fit/` (`index.html`, `notes.md`). Сайт только ночной (ADR-006), поэтому цвета знака — роли `--ink` и `--accent`, а не пара «день и ночь».

### Что есть

- Статика. `LogoMark` и `LogoLockup` (react) рисуют контуры из `docs/brand/logos-v2/nivel-1*.svg` без правок (тест сверяет пути с файлами), с `role="img"` и `aria-label` (по умолчанию «Nivel»; `decorative` прячет знак, если рядом есть текст). Для worker, PDF и бота — `logoSvg({ kind, ink, accent, label, width })` в ядре `@nivel/ui`: строка SVG, цвета по умолчанию из токенов ночи, без react и без CSS.
- Загрузчик. `LogoLoader` — инлайн-SVG и CSS, без WebGL: полка с треугольником качаются на острие на 5° и садятся на черту (1,4 с, по кривой концепта). Размер 48–96 px. Подпись («загрузка» на языке страницы) приходит снаружи, пустая отвергается. `role="status"`, `aria-busy="true"` всегда. При `prefers-reduced-motion` CSS останавливает качание и показывает подпись.
- Заставка. `LogoIntro` (react): сервер рисует статичный локап, он же остаётся при выключенном JavaScript, при «уменьшить движение» и на повторных заходах. После простоя браузера (`requestIdleCallback`, запасной таймер 200 мс) ядро грузится через `import()`, прогревается (`compileAsync` и один кадр вне экрана) и играет 3,3 с один раз за сессию, затем снова статичный локап и освобождение GPU. Без звука. При `prefers-reduced-motion` и в уже сыгранной сессии к `three` нет ни одного запроса.
- Ядро. `createLogoMotion(canvas, { mode: "intro" | "hero" | "static", onDone, caption, autoplay, startAt, onContextLost })` возвращает `{ ready, play(at), seek(t), time(), resize(), dispose(), duration, clicks }`. Сцена перенесена из прототипа: плита с гнёздами по контуру локапа, пять посадок со щелчком и отскоком, блик на фасках, ночной свет. Таймлайн — чистые функции в `src/logo-motion/timeline.ts` (позы деталей, отскок, блик, камера, лампа), на них же режутся щелчки роликов.

### Как подключать (WP-16, apps/web)

```tsx
import { LogoIntro, LogoLoader, LogoLockup } from "@nivel/ui/react";

// Первый экран: коробка с размером; компонент заполняет её целиком.
<div style={{ height: "min(70svh, 720px)" }}>
  <LogoIntro mode="hero" label="Nivel" />
</div>

// Шапка: статичный локап
<LogoLockup width={132} label="Nivel — bosh sahifa" />

// loading.tsx маршрута: подпись из пространства переводов common
<LogoLoader label={t("loading")} size={64} />
```

- `mode="intro"` (по умолчанию): заставка один раз, потом статика. `mode="hero"`: заставка и бесшовный повтор (камера «дышит» на ±2,2° и ±1,1°); для первого экрана.
- Заставка успевает, только если ядро готово не позже `introWindowMs` (1200 мс) после монтирования. Позже: `intro` остаётся статикой и не расходует сессию, `hero` идёт сразу в повтор. На первом визите без кэша `three` почти всегда не успевает, это ожидаемо (заметка концепта «Риски»).
- «Один раз за сессию»: флаг в `sessionStorage` (ключ `nivel:logo-intro`), все обращения в `try/catch`; если хранилище заблокировано или переполнено, флаг живёт в памяти страницы, исключений нет.
- `onDone` вызывается в конце заставки (в `hero` — в конце её части), `onError` — если ядро не загрузилось или нет WebGL (остаётся статика).
- Размер первой загрузки: `LogoIntro` и логика заставки не тянут `three`; он в отдельном чанке сборщика, который запрашивается только после простоя. Для `check-bundle-budget` считать чанк `three` не первой загрузкой.
- Прямой вход в ядро (без `LogoIntro`) и файлы роликов для бота требуют правки `exports` интегратором (файл `package.json` не принадлежит WP-09); блок в отчёте пакета:
  `"./logo-motion": "./src/logo-motion/index.ts"` и `"./media/*": "./media/*"`. `LogoIntro` работает и без этой правки: он берёт ядро относительным путём.

### Что исправлено в концепте для ночи (раздел «Известные ограничения»)

- Пятно лампы в 9:16 было похоже на виньетку: у верха и низа яркость падала до 20 % центра. Конус лампы теперь раскрывается под кадр (`lampForAspect`), яркость у верха кадра 9:16 — 72 % центра, как у квадрата. Фон за статичным локапом (`logoScene.stage`) снят с кадров и повторяет пятно, поэтому смена картинки не даёт скачка.
- Волосяная тень по низу букв: нижние фаски были на четверть темнее грани. Теперь на фаски, смотрящие вниз, падает тёплый отсвет от освещённой плиты (`chamferBounce`, растёт вместе с лампой); фаска ниже грани на 3 %.
- Полосы в тёмном градиенте пятна (8 бит дают кольца, видны на OLED): у плиты, стенок и дна гнёзд включён `dithering` three; при кодировании роликов цвет переводится в BT.709 с диффузией ошибки и теми же метками цвета, что у страницы.
- Холодный старт сохранён: `compileAsync` и прогревочный кадр до первого видимого, часы стартуют с первого реально отрисованного кадра, кадр длиннее 100 мс сдвигает отсчёт и не съедает время.
- Для `three` 0.186: `PCFSoftShadowMap` удалён из библиотеки, используется `PCFShadowMap`; шейдерная правка фасок проверена на новых чанках.
- Геометрия не требует `polygon-clipping` в браузере: объединение букв слова и плита запечены в `src/logo-motion/geometry-data.ts` (`scripts/bake-logo-geometry.mjs`, требует одноразовой установки библиотеки вне репозитория, зависимостью проекта она не является); тест сверяет запечённое с контурами SVG.

### Ролики для бота и Reels

`pnpm exec node packages/ui/scripts/render-logo-motion.mjs` (нужны `ffmpeg` в PATH, Edge и `@playwright/test` из корня) снимает ту же сцену покадрово (30 к/с, 3,4 с) в `packages/ui/media/logo-motion/`:

- `logo-intro-1x1.mp4`: 1080×1080, без звука, для бота;
- `logo-intro-9x16.mp4`: 1080×1920, со щелчками, начало Reels;
- `logo-intro-1x1.png`, `logo-intro-9x16.png`: постеры, финальный кадр.

H.264 (high), yuv420p (BT.709, метки цвета), faststart, вес каждого ролика не больше 1,5 МБ (сейчас 0,5 и 0,7 МБ) (скрипт падает, если больше; `--crf` меняет качество). Браузер скрытый, с новым временным профилем. После съёмки скрипт измеряет финальный кадр и падает, если пятно лампы похоже на виньетку (край/центр ниже 0,5) или нижняя фаска темнее грани больше чем на 10 %. `--shots <папка> --at 0.5,1.2` пишет кадры для просмотра, `--no-video` только постеры и кадры.

Звук синтезирован (`click-sound.ts`, без лицензий, одинаков при каждом запуске): сухой щелчок на каждую из пяти посадок, микрощелчки отскока (−14 и −23 дБ), выключатель лампы на 0,06 с, пик −3 дБFS. Для рекламы лучше записать настоящий щелчок алюминиевой детали в фрезерованном гнезде.

### Проверки

`logo/*.test.ts` и `logo-motion/*.test.ts` в `pnpm test`: контуры равны файлам бренда; разметка `LogoLoader`, `LogoLockup`, `LogoIntro` (SSR); ветка reduced motion без запросов к `three`; «один раз за сессию» с хранилищем, которое бросает исключение; граф импортов (вход `react` не тянет `three` статически, ядро заставки грузится в чистом Node); позы деталей во времени, отскок, конец заставки и шов `hero`; запечённая геометрия против SVG; сцена на заглушке рендерера (WebGL в юнит-тестах не нужен).
